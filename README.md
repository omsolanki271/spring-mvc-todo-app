# Spring MVC ToDo App

A simple ToDo application built using **Spring MVC**.
This project demonstrates basic **CRUD operations** and the **MVC architecture** using Java.

## Features

* Add new tasks
* View task list
* Update tasks
* Delete tasks

## Tech Stack

* Java
* Spring MVC
* JSP
* Maven
* Tomcat

## Purpose

This project was created for learning **Spring MVC fundamentals** and understanding how a web application works using the MVC pattern.
